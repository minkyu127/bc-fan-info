# BC FAN INFO — 블랙컴뱃 팬 정보 사이트 (비공식)

한국 종합격투기 단체 **블랙컴뱃**의 경기 일정, 선수 영입(블랙리스트·블랙 테이블), 전적, 랭킹, 선수 정보를
한곳에서 쉽게 보는 **비공식 팬 사이트**입니다. 블랙컴뱃과 관련 없는 개인 프로젝트예요.

## 기능
- **경기 일정**: 예정 대회(D-day), 지난 대회, 대회별 대진표·결과
  (넘버링, 블랙컵, 대항전, 라이즈, 챔피언스 리그 회차별, 비긴즈)
- **선수 영입**: 블랙리스트(차수별), 블랙 테이블(연도별)
- **전적**: 모든 대회 경기 결과, 판정 채점표, 선수 사진, 선수 이름으로 검색
- **블컴 뉴스**: 언론 기사(제목·링크)와 공식 유튜브 영상을 모아 기자회견·도발/신경전·영입·이슈·경기 결과로 자동 분류
- **랭킹**: 체급별 랭킹, 챔피언, 순위 변동
- **선수 정보**: 프로필, 통산 전적, 승리·패배 방식 통계, 검색·필터
- 선수 비교, 즐겨찾기(브라우저에 저장)
- 관리 화면: 데이터 자동 업데이트, 틀린 정보 직접 수정, 대회·영입 직접 추가

수집기는 요청 사이에 쉬는 시간을 두고, 받은 페이지를 저장해 두었다가 다시 씁니다.
선수 사진은 공식 홈페이지의 이미지를 링크로 보여주며, 권리는 블랙컴뱃에 있습니다.

## 내 컴퓨터에서 실행 (Windows)
1. [Python](https://www.python.org/downloads/) 설치 (설치할 때 "Add python.exe to PATH" 체크)
2. `시작.bat` 더블클릭
3. 브라우저가 열리고, 처음엔 5~10분 동안 데이터를 모아요

내 컴퓨터에서는 비밀번호 없이 관리 화면을 쓸 수 있어요.

## Vercel에 배포 (무료, 보기 전용)
1. Vercel에서 이 저장소를 Import → 설정 그대로 Deploy (`vercel.json`, `api/index.py` 사용)
2. 사이트는 저장소의 `data/blackcombat.db`를 읽어서 보여줘요 (관리·수정 기능은 꺼짐)
3. GitHub Actions(`.github/workflows/update-data.yml`)가 매일 아침 데이터를 새로 모아 DB를 올리면,
   Vercel이 자동으로 다시 배포해요. Actions 탭 → "데이터 자동 업데이트" → Run workflow 로 바로 실행할 수도 있어요.
4. 정보를 직접 고치고 싶으면 내 PC에서 `시작.bat` → 관리 화면에서 고친 뒤 `data/blackcombat.db`를 저장소에 올리세요.

## 서버에 배포 (항상 켜진 서버)
```bash
pip install -r requirements.txt
gunicorn -w 1 --threads 8 -b 0.0.0.0:8000 app:app
```
환경 변수
| 이름 | 설명 |
|---|---|
| `ADMIN_PASSWORD` | 관리 화면 비밀번호 (**꼭 설정**, 코드에 적지 말 것) |
| `SECRET_KEY` | 로그인 유지용 임의의 긴 문자열 |
| `AUTO_UPDATE_HOURS` | 자동 업데이트 주기(시간). 설정하면 서버 시작 시 데이터 수집 + 주기적 업데이트 |

> `-w 1`(프로세스 1개)로 실행해야 업데이트 진행 상황이 제대로 보여요.

VESSL AI 예시 설정은 [`vessl.yaml`](vessl.yaml)을 참고하세요.
